# apt-cacher-ultra 1.0.4 (proposed)

Fix Debian installer mirror checks failing with "mirror does not support the
specified release" when the cache already holds an adopted InRelease snapshot
([issue #30](https://github.com/linsomniac/apt-cacher-ultra/issues/30)).

The installer requests Release directly. Previously inline snapshots contained
only InRelease, and the proxy returned a local 404 even when the mirror had a
valid Release. Ordinary apt could still use InRelease after installation.

The proxy now derives Release and Release.gpg from the selected snapshot's
InRelease. This preserves the original signed message and every signature;
clients verify them with their existing repository keys. The proxy never mixes
upstream release files with an older snapshot's package indexes.

Upgrade and restart normally. Existing cached snapshots work immediately,
including offline. No cache deletion, database migration, configuration change,
or re-adoption is needed. Disabling adoption alone does not discard an existing
snapshot and was not a workaround for the old behavior.

The compatibility path checks the cached InRelease's SHA-256 before deriving
either response. If its file is missing, recovery accepts only an exact hash
match from upstream. Corrupt, unreadable, oversized, or malformed anchors return
502 with Retry-After; newer upstream content is never substituted. Derived
responses support HEAD, byte ranges, and content-based ETags.

This backport adds the same pure text splitter used by main to this serving
path. It does not change 1.0.x's signature-verification or adoption policies.
Each response uses one selected snapshot throughout. As with existing detached
repositories on 1.0.x, separate client requests spanning an adoption flip can
require a retry; this patch does not backport 1.1.0's flip barrier.

Validation: the full Go test suite with the race detector; offline upgrades of
copies of reproduced broken caches; the installer's wget/grep probe; GnuPG
verification; and real apt updates using the derived detached pair on Debian
10–13 and Ubuntu 14.04–26.04 LTS (eleven client versions, apt 1.0.1–3.2.0).
These checks cover the mirror probe and repository authentication, not a complete
installer VM run. The version is proposed; these notes do not publish a release.
